# AI Study Prompts

Reusable prompts for AWS Certified Machine Learning Engineer – Associate preparation.

---

## 1. Lesson Summary Prompt

```text
I am studying for the AWS Certified Machine Learning Engineer – Associate exam.

Summarize the following lesson in an exam-focused way.

For each important concept include:
1. What it is
2. When to choose it
3. When NOT to choose it
4. Similar AWS services/features that may be confused with it
5. Real-world example
6. Important exam keywords
7. 🧠 Exam Cheat Sheet

Keep the explanation concise but make the decision rules very clear.

Lesson:
[PASTE LESSON]
```

---

## 2. Practice Question Review

```text
Review this AWS Machine Learning Engineer practice question.

My answer: [ANSWER]

Do the following:
1. Give the correct answer.
2. Explain why it is correct.
3. Explain why every other option is wrong.
4. Tell me when each incorrect option would become correct.
5. Identify the trigger words in the scenario.
6. Extract a reusable exam rule.
7. Give a real-world example.
8. Finish with a short 🧠 Exam Cheat Sheet.

Question:
[PASTE QUESTION]
```

---

## 3. Compare Confusing Options

```text
Compare these AWS services or ML concepts for exam preparation:

[OPTION A]
[OPTION B]
[OPTION C]

Create a table with:
- Main purpose
- When to choose
- When not to choose
- Cost/operations considerations
- Typical exam keywords
- Short real-world example

Then give me a simple decision rule.
```

## 4. Generate a Similar Question

```text
Create one new AWS Machine Learning Engineer Associate scenario question
testing the same concept as the question below, but change the company,
requirements, wording, and answer order.

Do not reveal the answer until after I respond.

Original concept/question:
[PASTE QUESTION]
```

---

## 5. Weak-Area Review

```text
These are the topics I got wrong:

[PASTE MISTAKES]

Group them by concept.
Identify patterns in my mistakes.
Tell me the top 5 topics I should review first.
For each topic, give:
- the decision rule
- common trap
- one mini scenario
- one exam cheat-sheet sentence
```
